# Subnautica Enhanced Toolkit — 深海迷航 2026 全面增強與解鎖工具

Subnautica Enhanced Toolkit 是專為《深海迷航》（Subnautica）設計的 Windows 桌面綜合工具包。此工具旨在提供便捷的遊戲體驗調整，包括解鎖所有科技設計圖、啟用上帝模式、獲得無限氧氣、健康與資源，以及一鍵生成物品，讓您能更自由地探索潘多拉星球的深海奧秘。

## 主要功能

本工具提供以下核心功能，全面提升您的遊戲體驗：

1.  **一鍵解鎖全部設計圖**：立即解鎖遊戲內所有科技藍圖，無需從頭研究，快速體驗後期內容。
2.  **上帝模式**：啟用後，您將免疫所有傷害，並可在水下自由行動，無視壓強與氧氣限制。
3.  **無限資源**：可設定無限氧氣、無限生命值、無限電力以及物品數量，讓您在建造與探索時無後顧之憂。
4.  **物品生成器**：一個直觀的界面，允許您搜索並生成遊戲中的任何物品或資源，直接放入您的背包。
5.  **輕量級與安全**：工具以注入或記憶體編輯方式運行，不修改遊戲核心檔案，且注重使用者隱私與安全。

## 系統需求與安裝

**系統需求**：
*   作業系統：Windows 10 或 Windows 11（64位元）
*   遊戲版本：Subnautica（Steam 或 Epic Games Store 版本）
*   其他：.NET Framework 4.8 或更高版本（Windows 10 1809 及以後版本通常已內建）

**如何安裝**：

1.  從上方按鈕或下方連結下載最新的安裝程式，檔案名稱為 `Setup-latest15.07.exe`。
2.  在下載的檔案上按兩下滑鼠啟動安裝程式。
3.  依照安裝精靈的指示完成安裝過程，選擇您偏好的安裝目錄。
4.  安裝完成後，您可以透過開始功能表或桌面捷徑啟動工具。
5.  啟動工具後，它將自動偵測已安裝的《深海迷航》遊戲。若未偵測到，請手動設定遊戲路徑。
6.  啟動遊戲，在遊戲主選單或遊戲進行中呼叫工具（通常是透過快捷鍵），即可使用各項功能。

## 常見問題

**Q: 這個工具會讓我的遊戲帳號被封鎖嗎？**
A: 本工具主要針對單機版本的《深海迷航》設計，用於調整您的本地遊戲體驗。它不適用於多人模式或線上服務，因此不會影響您的線上帳號。請注意，在任何官方比賽或競技環境中使用修改工具都是不被允許的。

**Q: 工具支援 Epic Games Store 版本的遊戲嗎？**
A: 是的，本工具設計上同時支援 Steam 和 Epic Games Store 版本的《深海迷航》。安裝後，工具會嘗試自動定位遊戲安裝路徑，若未成功，您可以在設定中手動指向正確的遊戲執行檔位置。

**Q: 執行工具時，我的防毒軟體發出了警告，該怎麼辦？**
A: 由於工具的工作原理涉及對遊戲記憶體的讀取與寫入，一些防毒軟體可能會將其誤報為潛在威脅。這是此類遊戲輔助工具的常見現象。您可以將工具加入防毒軟體的白名單中。我們保證工具本身不含任何惡意軟體。

**Q: 工具的未來更新計畫為何？**
A: 我們會持續關注遊戲的官方更新與模組社群的發展，並計劃在必要時推出相容性更新。目前的版本（2026年）已針對最新版遊戲進行了充分測試。任何重要的更新都會在 GitHub 頁面發布公告。
